# 他撮りガイドカメラ(仮)Web試作

Xcode に進む前に、MVP の体験(選ぶ → 渡す → 点線に合わせて撮る → 5枚から選ぶ)をブラウザで確かめるための試作です。ビルド不要の静的ページです。

## 入っているもの

- お手本(テンプレ)を選ぶ画面。`templates.json` にサンプル2本
- 撮影者モード:背面カメラのプレビュー、点線シルエット、上下中央の線、傾きゲージ、シャッターだけ。左上の鍵マークを長押しするとオーナーの画面に戻る
- 5枚連写 →「本人に返してください」→ 5枚から選んで保存
- 端末内のログ(テンプレID、シャッター時のピッチとロール、手渡しから撮影までの秒数、撮り直しの回数)。ブラウザの中だけに保存し、送信しない
- 判定ロジックは `logic.js`(純粋関数)。テストは `test/logic.test.mjs`

## 動かし方

カメラと傾きセンサーは **https(または localhost)** でしか使えません。

- PC で試す:`npm run serve` のあと `http://localhost:8765/?sim=1` を開く。`?sim=1` を付けると、傾きをスライダーで動かせる
- iPhone で試す:Safari で https://ryuto794.github.io/tadori-cam-web/ を開く(GitHub Pages)
- テスト:`npm test`

## 骨格検出(実験用。既定では切ってある)

MVP の範囲外だが、次の段階に向けた準備として入れてある。URL に付けたときだけ動く。

- `?pose=1`:骨格検出で、点線とのずれを判定する。傾きが合ったあとに、高さ → 距離 → 位置の順で矢印を1つ出す
- `?pose=debug`:上に加えて、検出した関節を水色の点で表示する
- `&auto=1`:すべて合った状態が0.5秒続いたら自動で5枚撮る
- 判定は `pose-logic.js`(純粋関数)、テストは `test/pose-logic.test.mjs`
- 検出には MediaPipe Pose を使う。初回にライブラリとモデル(約6MB)を外部から読み込む。映像は端末の外に出ない
- 複数の人が写っているときは、点線の位置にいちばん近い人を被写体にする

分かっている限界:

- 人物の大きさは「まっすぐ立っている」前提で関節から推定している。座り、しゃがみ、大きく脚を開いた姿勢では小さく見積もる
- 関節の高さの比率(目、肩、腰、膝、足首)は標準的な体型の近似。実写で調整が要る
- 矢印の絵が撮る人に伝わるかは未確認

## iOS 版との違い(試作の限界)

- シルエットは汎用の人型を計算で描いている。本番はお手本画像から作った PNG に置き換える
- 1x レンズへの固定はできない。背面カメラを指定しているだけ
- 5枚は動画のコマを約0.2秒おきに切り出している。写真としての画質は iOS 版より低く、シャッター音は鳴らない
- 保存は共有シート経由(iPhone では「画像を保存」を選ぶ)。写真アプリへ直接は入れられない
- 傾きの見え方(線の動く量)は見やすさのために誇張している
